Where does your money go?

A tracer for the hidden flow of money through society.

    On the data. The income-tax allocation follows HMRC's Annual Tax Summary methodology (FY 2022–23 basis). Energy-bill trees use Ofgem's default-tariff-cap cost stack at the top level — identical across every supplier because Ofgem sets it — with each supplier-margin branch built from the parent company's most recent annual report or Companies House filing. All figures are illustrative and should be checked against current publications before being relied on.

    Each node carries a source line so claims can be traced. Many lower branches are deliberately stubbed — the structure is the point of this prototype, not the precision.

    Data lives in money-flow-data.json alongside this page. The page fetches it on load; if the fetch fails (e.g. opened as a local file) it falls back to a bundled copy. The UK National Minimum Wage is auto-refreshed weekly from gov.uk via a GitHub Action. Open an issue or pull request to refine anything.

    The bar above each level is a stacked proportional visual — each segment's width is its share of the total. Hover or click a segment to highlight the matching row below; click a row marked › to drill deeper. Slate-coloured segments and ↑ arrows follow money into another tree (e.g. VAT → UK Income Tax). Click a breadcrumb to step back up. Use the "Compare suppliers" toggle to view every energy supplier side by side.
