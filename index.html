Where does your money go?

A tracer for the hidden flow of money through society.

    On the data. The income-tax allocation follows the methodology of HMRC's Annual Tax Summary on a roughly FY 2022–23 basis. The British Gas breakdown follows Ofgem's default-tariff-cap cost stack, with the supplier-margin branch built from Centrica plc's most recent annual report. All figures are illustrative and should be checked against current publications before being relied on.

    Each node carries a source line so claims can be traced. Many lower branches are deliberately stubbed — the structure is the point of this prototype, not the precision.

    Data lives in money-flow-data.json alongside this page. The page fetches it on load; if the fetch fails (e.g. opened as a local file) it falls back to a bundled copy. Open an issue or pull request to refine the data.
